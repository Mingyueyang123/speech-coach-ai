# Speech Coach AI

Speech Coach AI 是一个本地优先的演讲、路演和主持陪练工具。它把台词卡、语音听众、摄像头录像、表达时间轴和知识库放在同一个练习工作台里。

## 能做什么

- 投资人 Pitch：模拟市场、壁垒、商业模式和融资问题。
- 客户路演：模拟 ROI、交付、数据安全和采购异议。
- 线下演讲：练习开场、故事、互动、转场和收尾。
- 每个目标按三轮递进：完整台词、关键词提示、完全脱稿。每轮独立录制和复盘，不会自动连续开始。
- 提词卡跟随所选实时识别服务的中英文结果，高亮当前段落；断线保留转写，暂停跟随，可主动重连或手动滚动。
- 摄像头预览可在布局内拖拽调整高度，也可收起。收起不会中断录像；“关闭摄像头”才会停止媒体轨道。
- 摄像头与麦克风本地录制，录像保存在浏览器 IndexedDB。
- 浏览器内计算语速、音量、面向镜头比例、手势活动和身体晃动。
- 对话式目标中心：用一句自然语言描述场合、听众和时间，自动拆解场景、日期、语言、期望结果与三轮任务，不要求填写复杂表单。
- 中文与英文训练全链路，包括识别语言、AI 听众、填充词、语速和复盘语言。英文复盘不评价口音优劣。
- 对话式灵感素材库：直接讲述观察或故事，由系统自动整理标题、类型、适用场景和受众边界。
- 素材入口仅保留外部知识库、文档上传和语音记录；目标和灵感对话复用语音识别，文字进入输入框，确认发送后才整理。
- 导入 DOCX、PDF、Markdown、TXT，也可读取授权的飞书文档。
- 支持阿里云识别 + DeepSeek 文本 + MiniMax 配音，也保留 OpenAI。听众只在点击“请听众回应”后提问；停止播放、继续发言和结束练习会取消待播放内容。

## 隐私边界

原始录像、摄像头帧和面部/姿态关键点不会发送到应用 API。AI 只接收转写、当前场景、相关知识片段和汇总后的表达指标。视觉反馈只描述可观察行为，不推断心理状态、人格、疾病或是否诚实。

浏览器会从 Google Storage 和 jsDelivr 下载 MediaPipe 模型与运行文件；模型推理发生在浏览器本地。

文档解析同样发生在浏览器内。和其他本地文档工具一样，只导入你信任的文件；应用不会把文件正文自动上传到第三方。

用户画像、训练目标、个人幽默素材、转写、复盘和三轮进度默认也只保存在当前浏览器的 IndexedDB。目标生成和 AI 复盘只发送当前任务需要的文本片段与汇总指标，不发送完整私人素材库。

## 对话优先

首次使用不要求填写角色、行业、经验等画像表单。用户可以直接告诉教练“什么时候、面对谁、要讲什么”，应用会自动识别投资人 Pitch、客户路演或线下演讲场景，并整理目标日期、时长、语言、期望结果和成功标准。

灵感素材同样通过对话记录，不要求用户先分类。没有配置所选文本服务或调用失败时明确使用本地模板；不会自动把内容发往另一家服务商。

## 三轮训练

1. 完整台词：建立内容、节奏和段落连接。
2. 关键词：只保留结构提示，检查是否能用自己的语言展开。
3. 完全脱稿：不显示台词，但继续记录转写、语音进度和表达指标。

完成一轮后，应用会先进入复盘。用户可以回练当前轮，也可以手动进入下一轮。目标复盘会并列显示三轮的语速、镜头连接和得分，避免用一个总分掩盖差异。

## 幽默训练与版权

内置方法卡只转述合法公开资料中关于逐字稿、真实观察、故事、节奏和公开试讲的通用训练主题，不复制书籍正文，不提供盗版文件，也不模仿李诞个人文风。延伸阅读：

- [《李诞脱口秀工作手册》豆瓣阅读正版电子书](https://read.douban.com/ebook/639784441/)
- [豆瓣公开书评](https://book.douban.com/review/13867613/)

线下演讲默认适合加入幽默练习；投资人 Pitch 和客户路演只在目标中提高幽默程度时使用，并优先采用轻度自嘲、具体观察和类比，避免攻击个人或受保护群体。

## 本地启动

```bash
npm install
cp .env.example .env.local
npm run dev
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。推荐桌面 Chrome 和耳机。既有用户继续使用原来的域名和端口，以保留该来源的 IndexedDB 数据。

开发和生产都使用同端口 Node 自定义服务器，同时承载 Next.js 和 `/api/speech/stream` WebSocket。开发热更新保留，默认只监听本机；不能部署为 Serverless，也不要用 `next start` 绕过网关。

```bash
npm run dev -- --hostname 127.0.0.1 --port 3003
# 生产模式
npm run build
npm run start -- --hostname 127.0.0.1 --port 3003
```

## 服务商配置

侧边栏 **API 配置** 提供“使用国内组合”和“使用 OpenAI”。密钥只写入本机服务端的 `local-data/api-config.json`（版本 2、0600 权限、未加密、Git 忽略），不回传浏览器。模型、地域及能力分配在高级设置。现有 OpenAI/飞书配置与环境变量兼容；保存其他 Key 不会自动切换服务商。一次只需配置你要用的能力。

| 能力 | 服务 | 必需配置 | 默认模型 |
| --- | --- | --- | --- |
| 连续识别、台词跟随、对话语音输入 | 阿里云 | 北京地域 API Key、Workspace ID | `qwen-audio-3.1-asr-flash-streaming` |
| 目标、素材、听众问题、复盘 | DeepSeek | API Key | `deepseek-flash` |
| 听众配音、试听 | MiniMax 中国站 | API Key、从列表选择的音色 | `speech-2.8-turbo` |
| 本地摄像头分析 | MediaPipe | 无 | 浏览器本地模型 |

先保存凭证，再测试。状态区分“已保存”“认证通过”和具体能力的“实际调用通过”，测试可能消耗额度。阿里云在收到真实识别结果后才标记识别成功；WebRTC 麦克风测试仅显示本次观察，不冒充所有模型均已验证。测试显示实测耗时，麦克风首结果时间包含等待说话，不能视为模型延迟基准。音色列表只读系统音色，不进行声音克隆。

没有任何凭证时仍可录像、查看台词和使用本地模板。只配 DeepSeek 就能使用文本能力，不要求配齐识别或配音。浏览器识别必须在高级设置中主动选择；它可能使用浏览器厂商的云服务，不等同于离线识别。

- OpenAI Key：实时听众、实时语音跟随、目标理解、素材整理和 AI 复盘共用一个 Key。音频通过 WebRTC 发送至 OpenAI，视频保持本地。
- 无 Key：主动选择浏览器 SpeechRecognition 后可尝试语音跟随，依赖浏览器支持、服务网络与权限。不会静默从付费服务切换到浏览器服务。
- 视频/姿态/表情：使用 MediaPipe，不需要 API Key；模型加载需要网络。
- 飞书：仅导入飞书资料需要 App ID、App Secret 以及对应文档的读取权限。

桌面提词使用 [Document Picture-in-Picture](https://developer.chrome.com/docs/web-platform/document-picture-in-picture)，在支持的桌面 Chrome 中可跨 App 置顶，可通过窗口边缘缩放、标题栏移动；关闭主页面会关闭悬浮窗。内嵌浏览器不支持时会明确提示，并保留页内拖动缩放。悬浮窗包含可隐藏和缩放的计时器，练习设置可以单独收起。录制中的计时使用实际开始时间计算，独立计时可开始、暂停和重置。

在 `.env.local` 中设置：

```bash
OPENAI_API_KEY=your_key
OPENAI_REALTIME_MODEL=gpt-realtime
OPENAI_REVIEW_MODEL=gpt-5-mini
```

API Key 只在 Next.js 服务端路由和本机 Node 语音网关中使用，不会进入浏览器包。

### 音频与数据边界

阿里云只接收单声道 16kHz PCM 麦克风音频；DeepSeek 接收必要文字；MiniMax 接收待朗读短文本。短问题使用 HTTP 配音，生成完成后播放，暂非逐字流式播报。播放器不接入识别音轨；耳机和回声消除仍有必要，外放可能被麦克风拾取。

网关校验本机地址、Origin、一次性短期会话授权、PCM 格式、帧大小和速率；关闭、断线、输入中断或达到最长时限时清理连接。正常结束最多等待约两秒收取最后一句，随后强制关闭。取消本机请求会中断等待和播放，但供应商已执行的生成仍可能计费。

普通练习记录增加无密钥的服务商/模型快照。没有清空或重建 IndexedDB，旧记录保持可读。自动化使用独立临时配置目录和模拟供应商，不使用你的私人凭证。

### 沉浸式扩展预留

`src/lib/immersive.ts` 定义场景、角色、音色、事件时间轴及可替换形象接口。环境底音、突发音效、观众配音有独立音量和统一暂停/取消接口，已用模拟音轨测试。首个形象约定为音频驱动圆环；本轮没有可点击的沉浸模式、真人数字人或视频上传。

未来环境音采用授权素材或预生成缓存，[ElevenLabs 音效 API](https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert)仅为候选，本轮无需 Key 或付费。

接口依据：[阿里云实时 ASR](https://help.aliyun.com/zh/model-studio/qwen-audio-asr-streaming-websocket-api)、[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[MiniMax 配音](https://platform.minimax.io/docs/api-reference/speech-t2a-http)、[MiniMax 音色](https://platform.minimax.cn/docs/api-reference/voice-management-get)。

## 飞书配置

创建飞书企业自建应用，为它开启云文档和知识库只读权限，并确保该应用可访问目标文档。然后设置：

```bash
FEISHU_APP_ID=your_app_id
FEISHU_APP_SECRET=your_app_secret
```

在知识库页面粘贴 `/docx/` 或 `/wiki/` 链接即可导入。服务端仅负责读取并返回标准化正文，不持久化资料。

## 验证

### 台本与个人表达迭代

- 提词卡的「编辑台本」可直接修改全文；保存会创建新版本、同步第二轮关键词，并从第一轮重新练习。「历史版本」可载入旧稿后另存为新版本。
- 「从知识库生成」选择资料并用一句话描述要求。使用已配置的 DeepSeek 或 OpenAI 文本服务整理台本；没有凭证时仍可直接载入最多 6 段相关原文并编辑，不把原文拼接冒充 AI 生成。
- 每次新练习保存当时的完整场景/台本快照、版本 ID、转写、复盘及评分来源。改稿不会改变过去的记录。旧记录缺失原稿快照时不提供伪造的历史对照。
- 「练习迭代」按已保存分数展示同场景记录，可自行选择参考表现；区分同一原稿的练习，提示本地估算与 AI 分数、不同轮次并不完全可比。支持逐句增删对照及 AI 提炼，单次高分不代表改动造成提分。
- 只有用户勾选并确认的建议才写入本地表达记忆。每条包含发言依据、来源记录和语言/场景范围；生成下一版和新的目标计划时最多使用 8 条匹配的已确认习惯。可在「表达记忆」忘记规则。删除录像不会自动删除另行确认的表达记忆；已保存的稿子不会因此被自动重写。
- AI 返回的引用须能在对应原稿/转写中找到，否则不显示为依据。这是可管理的本地偏好记忆，不是对基础模型进行训练。
- 新接口 `POST /api/scripts/coach` 严格校验请求与结果。只发送用户选定的那次原稿、实际发言、必要评分指标、最多 6 段所选资料和确认过的偏好，不上传录像、关键点或全部历史。生成失败保留原稿；对照失败明确退为本地文本对照，不自动换服务商。
- IndexedDB v3 增加 `scriptVersions` 和 `coachMemories`，保留原有资料、目标、设置与录像。新稿先预览，确认保存后才用于下一次练习。

### 平板工具栏

- 左侧导航可折叠，偏好保存在原 IndexedDB。iPad 与窄屏保持镜头在上、台词在下，不自动把台词提前。
- 横向工具栏在所有栏目持续存在；语言、场景、听众、设备、台词和计时设置按需弹出。台词与计时器是独立窗口，各自移动、触控拖拽缩放、隐藏。隐藏不会停止录制或计时。
- 开始前确认语音跟随或匀速滚动；开始后台词区只保留正文和移动/缩放手柄。倒计时目标可调整，最后一分钟显示红色提醒，到时不自动结束录制。
- 麦克风/相机使用所选设备 ID，录制中禁止切换。支持仅录音，以及浏览器支持的 WebM/MP4 格式。没有视觉分析时，复盘不评价眼神和姿态。
- 输出选择通过 `setSinkId` 实际路由听众配音和本地试听音。设备授权失败不会静默换设备。浏览器原生 SpeechRecognition 的输入由浏览器/系统管理；阿里云和 OpenAI 识别使用应用采集的所选麦克风。
- [Document Picture-in-Picture](https://developer.mozilla.org/en-US/docs/Web/API/Document_Picture-in-Picture_API) 支持的桌面浏览器可将一个工具置顶到其他 App 上方，每个标签最多一个置顶窗口。iPad Safari 不支持任意 HTML 跨 App 悬浮，应用内悬浮不等于系统级悬浮；切到后台也不能保证录制或识别继续。
- [音频输出选择](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/setSinkId) 按能力检测提供。未支持时通过 iPad 控制中心选择耳机；本地试听不调用任何付费 API。
- 默认开发服务仍只监听本机。服务器部署也保持 Node 进程监听回环地址，可通过反向代理提供带认证的 HTTPS；设置 `SPEECH_COACH_ALLOWED_ORIGIN` 后仅接受该精确 HTTPS 来源及本机同源请求。不要把含 API 配置入口的 Node 端口直接暴露到公网。
